# Landing page de reflexologia podal

Página de destino para o serviço de reflexologia podal relaxante do Espaço Ana Carvalho, em Sorocaba.

## Arquivos

- `index.html`: landing page responsiva com as seções O que é, Para quem é e Vantagens, chamada para agendamento via WhatsApp e metadados de compartilhamento social.
- `assets/logo-horizontal.png`: logotipo horizontal usado no cabeçalho.
- `assets/favicon.jpg`: favicon da marca.
- `assets/social-preview.png`: imagem Open Graph para prévias em WhatsApp e redes sociais.

A página usa a foto pública de Ana Carvalho hospedada em `anamanicure.com.br`.

O texto apresenta a reflexologia como prática complementar de bem-estar; não promete prevenir, diagnosticar ou tratar doenças. Preço e duração ficam para confirmação com a Ana.

## Visualização

Abra `index.html` localmente no navegador. No GitHub Pages, a publicação é configurada pela branch `Mockapps` e pela pasta raiz.
