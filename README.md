# Landing page de reflexologia podal

Página de destino para o serviço de reflexologia podal relaxante do Espaço Ana Carvalho, em Sorocaba.

## Arquivos

- `index.html`: landing page responsiva com as seções O que é, Para quem é e Vantagens, agendamento via WhatsApp e metadados sociais.
- `assets/logo-horizontal.png`: logotipo horizontal do cabeçalho.
- `assets/favicon.jpg`: favicon da marca.
- `assets/social-preview.jpg`: imagem Open Graph para WhatsApp e redes sociais.

Paleta: `#b39e8a`, `#25ac99`, `#f4f4f4` e `#ffffff`. A página usa a foto pública de Ana Carvalho hospedada em `anamanicure.com.br`.

O texto apresenta a reflexologia como prática complementar de bem-estar; não promete prevenir, diagnosticar ou tratar doenças. Preço e duração ficam para confirmação com a Ana.

## Visualização

Abra `index.html` localmente. No GitHub Pages, a publicação está configurada pela branch `Mockapps` e pela pasta raiz.
