# Landing page de reflexologia podal

Página de destino para anúncios do serviço de reflexologia podal relaxante do Espaço Ana Carvalho, em Sorocaba.

## Visualização

Abra `index.html` localmente no navegador. O site pode ser publicado com GitHub Pages nas configurações do repositório.

## Conteúdo

- `index.html`: página responsiva com apresentação, dúvidas frequentes e chamadas para agendamento via WhatsApp.

Preço e duração da sessão não foram incluídos porque precisam ser confirmados com a Ana.
